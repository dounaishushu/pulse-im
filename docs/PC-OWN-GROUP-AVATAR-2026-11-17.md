# PC 群聊自己消息的头像修复

对应 PC **2.4.175 / Windows x64**，2026-11-17。

## 原因与修复

已发送消息的渲染器已经生成自己的头像节点，但 `desktop-chat.css` 默认隐藏 `.classic-message-avatar`，随后只对私聊重新显示，导致群聊中的头像即使加载成功也不可见。修复前在完整 PC 页面复现：群聊文字、图片、视频容器及长文字的四个头像图片均已解码，头像框却都是 `display:none`、宽高为 0。

现在群聊自己消息的头像显示在气泡右侧，预留 42 px 位置；文字、图片及已读状态按可用宽度排布，避免头像越出聊天区。保留原有私聊和其他群成员头像布局，系统提示继续采用原来的样式。浅色、深色和较窄窗口均已检查。

待发送文字和图片上传的渲染器原来也只为私聊生成头像，现已补齐群聊自己的头像。文字待发、确认成功及图片上传状态使用当前账号头像；头像为空或不可访问时保留已有的昵称首字占位与恢复逻辑。

本次没有新增头像查询接口，使用当前账号已取得的头像。无需服务端部署。

## 验证与交付

- 完整 PC 页面检查 **11 项通过**：群聊四类消息的单个已解码头像、右侧位置及边界、其他成员头像、深色主题、980 px 窗口、私聊、当前头像清空、图片不可访问占位、草稿保留、真实待发文字队列与确认替换，以及实际图片待发渲染器。媒体与发送确认均为本机夹具，不向真实群发消息；视频只检查消息容器与头像布局，不测试视频解码。
- 既有头像恢复页面检查 **17 项通过**，覆盖旧授权失败、新授权恢复、列表与顶部联动、账号隔离及聊天草稿。
- 客户端单元检查 **123 项通过**；PC JavaScript 语法检查和 `git diff --check` 通过。
