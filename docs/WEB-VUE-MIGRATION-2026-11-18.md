# Web Vue 完整迁移、逐文件对照与上线记录

用户 Web 已迁移为 Vue 3 + Vite + TypeScript；首版 `2.4.192` 的发布记录保留在本文。本次追加 Web `2.4.193` 多账号同时在线能力。当前代码已完成 48 个旧 JS/CSS/HTML 文件的逐文件行为对照，建立 710 个具名函数/方法的去向索引，另外核对 3000 个原静态资源。

源码对照是迁移范围判断的依据；构建与浏览器检查仅作补充。这里的“完成”指清单内的旧功能已找到对应实现或明确保留原有不可用边界，不代表任何环境下都不会出现缺陷。

## 登录问题及已修复原因

原登录接口确实可以成功返回 200 和 session，但生产首页遗漏 `message-scroll.js`、`group-mentions.js`、`group-mentions.css`，Nginx 又将不存在的资源回退为 HTML。浏览器拒绝执行这些文件，登录后的旧工作台初始化随之抛错；旧 boot 又把所有初始化异常都当成登录失效处理。

已补齐完整旧资源以先恢复原站，配置缺失静态文件返回 404，并修复旧 boot：只有 401 清会话，其余初始化错误保留 token、显示可重试界面。Vue 入口也保留这个处理原则，并处理异步组件和发布后 chunk 加载失败。`web.imapi.shop` 的旧入口继续跳转至正式 HTTPS 入口。

## 从逐文件对照中补齐的差异

- 注册规则和确认密码显隐、tab 键盘访问；成功登录后先保存 token。
- 新好友持久游标与自动打开会话；选择文件/录音期间不抢走当前会话。
- 草稿、光标/选区、提及对象与侧栏预览；消息复制保留段落但排除时间和头像。
- 群成员头像右键管理、每次操作重新取选中成员权限；好友名片保留来源消息的授权上下文。
- 完整转发选择器、收藏夹、多选上限、每接收者/消息幂等请求号及部分失败续发。
- 附件上传结果和请求号跨重试保留；已确认发送的附件跳过；切换会话后不会误发到新会话。
- 普通成员 @ 搜索、中文输入法、上下/Enter/Escape、关键词匹配后再显示 @所有人。
- 两栏群成员候选、默认群头像、邀请容量与隐私限制；服务端最多单批 50 人，分批提交并保留失败项。
- 图片和头像按内容身份复用节点；失败后两次自动恢复、手动重试；GIF、自动加载范围/大小与音量设置实际接入。
- 本人发送滚动到底部；用户上翻与程序重排区分；图片/视频/视口变化跟随；历史和定位不强制拉底。
- 首屏可先显示已授权历史页，媒体授权不会卡住全部文字；初始历史失败重试最近一页，避免从头拉取大量历史。
- 设置页加载完成前禁止保存默认空表单；取消/切页不让旧响应覆盖新页；正式构建的模块导出已单独核对。
