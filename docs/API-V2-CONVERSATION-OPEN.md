# 会话打开与批量媒体授权

## 幂等打开会话

```text
POST /api/v2/conversations/{conversation_uuid}/open
```

请求必须使用有效用户会话。服务端检查真实成员身份和会话状态，仅在当前用户隐藏了会话时取消隐藏；重复或并发打开不会重复推进偏好版本，也不会改变置顶、归档、静音等其他设置。返回经过权限校验的完整 `ClientConversation`，包含原始 UUID、类型、成员版本和当前用户状态，不返回只有 `status` 的操作摘要。

PC/Web 和 Android 均校验响应对应请求的会话。旧服务没有该端点时，客户端退回原接口，并在隐藏恢复遇到偏好版本冲突时重新读取权威状态。返回操作摘要而缺少会话信息时，也重新读取完整信息；错误的其他会话标识不会被覆盖为当前标识。

Go 的 `kind: "saved"` 在保留的界面契约中映射为 `type: "favorites"`。该转换适用于 PC/Web 与 Android；服务端继续保留自己的 `saved` 类型和权限规则。

## 批量媒体授权

```text
POST /api/v2/media/grants
Content-Type: application/json

{"media_ids":["媒体 UUID", "另一媒体 UUID"]}
```

单次最多 128 个标识，重复标识合并。响应 `items` 中每个元素包含请求的 `id`，以及 `access` 或 `error`。允许访问的 `access` 与原单个媒体授权接口保持同样的 120 秒时效和会话绑定；不可访问项只返回权限错误，不影响其他合法项取得授权。非法 UUID 或数量超限拒绝整个请求，撤销会话或失去消息可见性后原授权仍会失效。

客户端预取历史消息、引用、头像和会话摘要所需授权，减少逐张图片的串行网络请求。新客户端可回退到旧服务的单个授权接口。某个头像或已不可访问附件的授权失效，不应该通过伪造地址或跳过身份验证来打开内容；界面保留消息，其媒体标为不可用。401 登录失效继续向上报告。

Android 0.2.86 在上传就绪回执和提交消息之间携带短期授权。待发附件保存的授权带绝对到期时间、端点和会话摘要；发送前仅在它仍有效且属于相同会话时复用。授权不写入消息正文，过期、换号或重新登录后重新申请。
