## 前端阻断项

1. **Web/PC：普通入口尚未全量改接。** `web/app.js`、`pc/web/app.js` 虽然统一调用 Go 适配器，`client-shared/go-v2.js` 仍只覆盖部分旧请求。源码字面量调用对照至少有 Web 12 个、PC 17 个未映射的路径；动态路径尚未计入。直接运行适配器验证 `/auth/register`、`/auth/register-challenge`、`/auth/profile` 和非文字 `/messages` 均在发出 HTTP 前返回 501。
2. **Web/PC：历史媒体在视图转换中丢类型。** `client-shared/go-v2.js` 的 `message()` 对任意 Go 消息固定输出 `type:'text'`，忽略 `kind`、`content` 和媒体授权；图片、视频、语音、文件、名片、引用和提及无法按原功能显示或发送。`web/app.js` 的 `uploadMedia()` 在 Go 模式直接 501；群头像选择、消息置顶、日期定位、收藏/文件夹、会话偏好等路径仍未接通。客户端更新检查仍按旧 `latest_version/force_update` 字段读取 Go `/client/config`，需接 `/client/update` 才能验证强制升级语义。
3. **Android：Go 模式默认启用，但功能被关闭。** `ApiClient.kt` 的附件上传和诊断上传直接 501；`GoV2Api.kt` 只发送文字，拒绝引用、@ 和非文字；`MainActivity.kt` 在 Go 模式清空并隐藏置顶消息。群头像、注册及部分设置/历史能力未形成完整 Go 链路。
4. **iOS：适配器仍为部分映射。** `APIClient.swift` 在 Go 模式拒绝媒体和语音上传；`GoV2Adapter.swift` 只发送纯文字，其他旧请求落入 `unsupported`。Release 的 `PULSE_API_URL` 仍为示例域名；本机无 Mac，未进行 Xcode 构建或真机验收。
5. **独立后台：仍是旧 PHP 协议。** `admin/src/app.js` 生产默认请求 `${location.origin}/api`，`admin/src/entry.js` 请求 `/api/admin/auth/entry`，且沿用旧的响应包裹、CSRF 头和后台路由。Go 后台使用 `/api/v2/admin/...`、独立 Cookie、`X-Admin-Entry` 和 `X-CSRF-Token`；未见后台 Go 适配层。当前旧后台入口 503，后台页面无法管理新库。
