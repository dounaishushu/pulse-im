核对的操作入口包括消息、联系人、群聊、通知、收藏、账号和设置，聊天搜索和资料，群通知、邀请及管理，表情、截图、附件、视频、拍照、录音、@、名片、窗口抖动和发送。会话右键及消息菜单按权限提供置顶、静音、归档、未读、备注、清空历史、回复、转发、多选、编辑、撤回和回执。语音或视频实时通话、在线翻译和在线客服延续旧版服务能力，入口显示提示。截图、摄像头、麦克风和系统剪贴板取决于浏览器许可。

Web 浏览器验收使用本机隔离的 PostgreSQL、Redis 和 Go 服务，覆盖登录与刷新、多账号隔离和恢复、消息与受保护图片、搜索和历史、权限、附件编辑以及群组和通知面板。慢请求测试验证了 Web 的一个阻塞路径及其恢复。11 月 19 日记录到的服务端短时延迟属于独立现象，底层根因仍待确认。Android `0.2.110` 为可覆盖旧测试版的测试签名包。iOS 的目录协议变更随源码保留，真机验收待完成。

第一次上线后再次按旧版源码检查设置入口，发现漏迁两个操作。Web `2.4.198` 补回了隐私页的「添加屏蔽用户」。联系人按需分页，支持根据昵称、账号、备注和 ID 筛选已加载的结果，可取消、屏蔽或解除。通话记录里的「通话设备设置」直接打开输入和输出设备页，关闭后回到通话记录。两项均在 Chrome 中连接隔离 Go 服务验收，屏蔽和解除另核对了服务端记录。

视频中的「添加账号」返回问题也已修复。浏览器后退会退出添加流程并回到原来的聊天，打开账号管理窗口后再进入添加流程时也会恢复该窗口。浏览器回归覆盖后退和前进、原群聊和文字草稿、继续添加账号及已登录账号保持在线。
