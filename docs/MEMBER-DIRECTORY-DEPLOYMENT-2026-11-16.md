## 审查范围和结论

本轮检查该提交的 `server/internal/core/client_http.go`、`client_queries.go`、`groups.go`、`member_directory_test.go`，并沿认证、群角色、好友关系和客户端适配器核对接口契约。此次结论针对 Go 发布范围，不代表本轮重新验收全部原生客户端界面。

- 认证仍由用户会话校验、`lockIdentity` 和群成员授权组成；停用、退出登录、移出群后的访问被拒绝。
- 搜索使用参数化 SQL，并转义 `%`、`_` 和反斜杠，不把用户输入拼成 SQL。
- 普通群员默认成员列表只展示群主和管理员；输入关键词后，仅返回本群内自己的好友，不包括自己、非好友或群外好友。
- 群主和管理员可查看、搜索全部有效群成员。`block_member_friend_requests` 开关不会放宽普通群员的目录范围。
- 按昵称、本人备注、账号和公开 ID 做包含匹配；每页 1—100 条，关键词最多 100 个字符，UUID 游标排序，使用 `limit+1` 判断下一页。
- 每次请求重新获取当前角色及好友关系，旧游标不能绕过角色降级、删除好友和群成员移除。
- 响应保留旧 `items`、`next_after`，新增 `query`、`search_scope`、`members_visibility`、`is_contact`；旧默认列表请求仍可读取。普通成员目录收紧是作者此提交的明确功能规则。
- `search-members` / 输入框 @ 使用原有独立入口；本次目录规则不赋予普通群员 @ 全体或管理群权限。
