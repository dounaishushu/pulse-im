# 客户端聊天修复记录

日期：2026 年 11 月 16 日，北京时间。

本记录覆盖本轮客户端续修及配套 Go 成员目录接口，接续此前的 [服务器与后台反馈修复](IM-FEEDBACK-DEPLOYMENT-PACKAGING-2026-11-16.md)。此前文档中暂停客户端、尚待客户端处理的描述是当时的交付状态，应结合本记录查看。

## 改动

### PC 群通知、禁言与布局

- 移除聊天顶部的两个邀请入口，将原有聊天工具移到右侧。
- 群通知设置保留最新偏好版本，避免较旧响应覆盖刚保存的开关；免打扰会话的未读数字使用灰色样式。
- 群资料更新复用现有消息和图片节点，降低通知开关与实时回声触发的闪烁。
- 恢复关闭通知时原有的 32 像素图片图标。
- 全员禁言写入群禁言接口，按钮显示“开启禁言／解除禁言”；普通群员的输入框显示“已开启禁言”，群主、管理员仍按服务端权限发言。

### PC 群发窗口关闭后继续发送

点击发送后，关闭按钮、Escape 和点击窗口外部只隐藏群发界面，已启动的任务继续发送。重新打开窗口复用当前任务和进度；选择的接收者、附件、请求 ID 和已完成状态保留，避免重复提交。

明确停止及账号退出仍结束对应任务。账号、会话和权限校验继续生效。

### 私聊、群聊的新消息定位

- PC、用户 Web、Android 和 iOS 收到或发送新消息时恢复跟随最新消息。
- 延迟图片布局、列表尺寸变化及键盘引起的视口变化不再误判为用户主动查看历史。
- 用户主动上翻暂停当前跟随；加载旧消息、元数据刷新继续保留阅读位置。账号、会话及历史版本变化隔离滚动状态。
- 浏览器滚动和群 @ 模块由 `client-shared` 同步到 `web`、`pc/web`，维护时应运行同步脚本。

### 普通群员输入框 @ 搜索

普通群员可以输入 @ 并进行模糊搜索、选取有权提醒的成员。普通群员候选不显示名字后的账号和公开 ID，选中后保留实际接收者身份；编辑或删除已选提及时移除失效身份。

群主、管理员保留原有账号显示和 @ 全体权限。普通成员不会取得 @ 全体权限；禁言和服务端搜索可见范围继续生效。

### 群资料成员列表与好友搜索

- 普通群员默认成员列表只显示群主和管理员，不受“允许成员互加好友”开关放宽。
- PC 群资料输入搜索词后，普通群员只搜索本群内自己已添加的好友，按名称、本人备注、账号或公开账号 ID 进行包含匹配；非好友、群外好友及自己不会进入其搜索结果。
- 群主、管理员保留全部群成员的查看和搜索能力。
- Go 的成员目录查询在数据库层执行成员、角色和好友范围限制，翻页时重新检查权限。带关键词的 `GET /api/v2/groups/{id}/member-profiles` 接受 `q`、`after`、`limit`，返回 `query`、`search_scope`、`members_visibility`、`items`、`next_after`。
- 浏览器适配器补齐群资料界面所需的查询、页码、好友标记及范围信息，修复“搜索结果或权限已变化”的格式错误；分页状态按登录会话、群、角色和查询词隔离。
- Android、iOS 和用户 Web 同步默认成员列表限制。聊天输入框的 `search-members` / @ 搜索保留原有独立逻辑。

**好友目录搜索必须同步更新 Go 服务端和 PC 客户端。此次仅完成代码和本地构建，尚未部署线上服务。**

### Android 图片发送提示

图片正常保存入队、排队、上传和提交期间，不再向聊天消息区域插入文件名、“正在保存待发附件”“等待发送”“正在上传”及“移除”文字占位。发送队列仍处理上传和回执，失败条目保留重试操作。

iOS 原生聊天没有这组左下角待发附件文字，本次对应的隐藏调整在 Android。
