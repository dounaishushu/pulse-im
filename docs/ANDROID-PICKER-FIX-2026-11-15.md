# Android 0.2.87：相册返回后附件丢失修复

日期：2026-11-15（北京时间）。版本：`0.2.87`，`versionCode = 89`。源码标签：`android-v0.2.87`。

## 已确认的问题与修复

原作者反馈模拟器选图后无法发送。提供的 logcat 中约 5 ms 的 GC 等待不足以解释这次失败；实际安装 `0.2.86` 后，通过聊天附件按钮打开真实相册、选择 MediaStore 图片、预览并点发送，在 Android 12 / API 31 和 Android 16 / API 36 均复现：打开相册触发聊天页 `onPause()`，会话重校验把权限暂设为 `loading`，旧代码同时清除了待发目标，接收端收到 0 张图片。

`0.2.87` 保留选图时捕获的账号、令牌、接口地址和目标会话。结果回调先保存选择；等聊天页恢复前台并完成最新会话权限校验，再一次性加入现有加密待发队列。使用重建后的消息容器，避免继续向旧页面添加进度。真正的禁言、隐私拒绝、成员身份变化、账号/会话切换及退出登录仍会取消选择。

同类修复包括：

- 拍照、视频和文件返回共用上述结果处理入口。
- 相机权限拒绝、没有相机或没有可用选择器时清理待发状态；选择器启动失败转为可重试提示。
- 连续点击附件入口时避免重复打开选择器。
- 个人头像选择捕获原账号和原令牌，消费一次结果；切换账号或令牌后不继续修改旧账号头像，上传及保存前再次校验。

## 实际验收

两套模拟器均实际覆盖安装发布的 `0.2.86`，先复现，再覆盖安装本次 `0.2.87`。验收连接独立的 Go / PostgreSQL / Redis 测试服务，未修改生产账号和生产消息。

| 场景 | API 31 | API 36 |
| --- | --- | --- |
| 0.2.86 真实相册选 JPG 后点发送 | 目标丢失，收到 0 张 | 目标丢失，收到 0 张 |
| 0.2.87 JPG / PNG 真实相册、预览、发送 | 各收到一次，接收图片可解码 | 各收到一次，接收图片可解码 |
| 多选两张原图发送 | 两条消息，下载字节 SHA-256 与源文件一致 | 同左 |
| 取消相册、迟到的重复结果回调 | 无额外消息，待发目标清理 | 同左 |
| 选图期间由接收账号实际修改隐私，撤销发送权限 | 返回后重新校验并拒绝发送 | 同左 |
| 相机拒绝权限回调、启动不存在的选择器 | 状态清理，不堵塞后续操作 | 同左 |
| 真实个人头像选择、上传、下载解码 | 通过 | 通过 |
| 头像选择期间切换保存的当前账号 | 丢弃旧选择，未修改旧账号头像 | 同左 |
| 原图大小限制、加密附件、旧格式恢复、300 张待发队列顺序和重试 | 通过 | 通过 |

相机权限拒绝和迟到回调使用系统回调边界注入；没有把它们称为真实拍照验收。头像换号使用测试账号状态切换。没有执行所有品牌相机、第三方文档提供器、实体手机或离线推送验收。API 31 / 36 的通过结果不能替代作者手机上的安装确认。

`PhotoOriginalChecks` 中旧的“恢复后所有条目都要手动 retry”断言已按现有队列语义更新：原来处于 QUEUED 的条目自动恢复；FAILED 条目仍需要显式重试。测试继续校验 300 张顺序、中途失败、原图标志及消息去重，没有放宽产品的重试或权限规则。

## 交付与复现

附件 `Android-0.2.87-validation.apk` 为与上一验收包相同密钥签名的调试 APK，可以覆盖本轮 `0.2.86`。原正式签名文件和 Firebase 配置仍缺，正式签名发布由作者按 [打包交接说明](CLIENT-PACKAGING-HANDOFF-2026-11-15.md) 补齐；本次不交付 IPA。

APK SHA-256：`e473dad9b2463c123ea3e49ab94f3af161901381075170034af673df3a806673`。

入口：`PickerSendChecks.kt` 经 `GoV2Probe` 的 `live=picker-send` 分支运行。使用独立测试库和以 `picker` 开头的三个测试账号；参数为 `base`（模拟器到本机测试服务的 URL）、`prefix`、`password`，可加 `baseline=true` 复现旧包。

```powershell
cd android
.\gradlew.bat assembleDebug assembleDebugAndroidTest `

```

生产交付包使用上述 HTTPS / WSS；仅在仪器测试中使用模拟器测试服务覆盖。测试报告随 Release 的 `validation-evidence.zip` 提供，不包含账号密码、令牌、用户私有图片或生产原始日志。
