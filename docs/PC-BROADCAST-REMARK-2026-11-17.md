# PC 群发好友备注搜索修复

对应 PC **2.4.172 / Windows x64**，2026-11-17。

## 原因与修复

群发目标接口 `/api/v2/broadcast-targets?kind=friend` 返回好友昵称和账号，没有好友备注。原群发窗口也仅匹配 `name` 与 `username`，因此聊天列表里按备注显示的“测试…”好友，在群发窗口输入相同备注会显示没有匹配结果。

群发助手现在复用 PC 已有的 `PulseContactNames` 控制器，通过现有 `/api/v2/client/friend-page` 分页取得当前账号的备注。好友目标和备注并行加载，列表优先显示备注，搜索同时匹配备注、原昵称和账号，支持子串、大小写及全角输入。修改或清空备注时，打开的群发列表同步更新，清空后不继续匹配旧备注。

`/contacts/names` 适配路径只读取好友元数据，不等待头像授权。普通好友列表 `/contacts` 的头像处理保持原逻辑。备注加载失败显示重新加载入口，手动重试可立即重新请求；群组列表单独加载。无需新增或部署服务端接口。

勾选及发送仍使用 `type + ID`，搜索不会重置已选好友；全选只作用于当前搜索结果。群组搜索、关窗继续群发、显式停止、重试请求 ID、账号切换和权限撤销的逻辑保留。备注按当前登录账号隔离，展示内容经过转义。

## 验证

所有页面测试使用本机夹具和模拟响应，没有向真实好友发送群发消息。

- 故障基线：真实群发窗口加载 112 位好友后，输入“测试”命中 0 人，复现截图问题。
- 备注搜索页面检查 **11 项通过**：两页 112 位好友、第二页备注、昵称和账号、按搜索结果全选、跨好友与群组选中状态、备注修改及清空、12 个目标按原 ID 发送、账号隔离、慢请求、失败后立即重试、加载时关闭窗口。
- 既有群发页面检查 **8 项通过**：关闭、重新打开、上传时关闭、Escape、背景关闭、显式停止与重试、账号退出/切换、权限撤销。
- 客户端单元检查 **118 项通过**，包含新加的备注分页不加载头像、普通好友头像保持加载和账号切换拒绝旧响应三个检查。
- 既有头像页面检查 **17 项通过**，包括完整 PC 页面中的会话列表、聊天顶部和草稿；PC JavaScript 语法检查及 `git diff --check` 通过。

## 安装包

`小猿口算-2.4.172-Go-Windows-x64.exe` 包含此前 PC 2.4.171 的头像恢复、2.4.170 的版本检查后台重试，以及当前工作区已有的聊天修复。沿用生产 HTTPS/WSS 配置和现有 Windows 构建方式。

交付目录包含测试结果与截图、ASAR 内应用文件与源码比对、构建前后源码指纹、EXE 版本信息和 SHA-256。安装包尚需用户安装后，在真实账号中确认原有备注可搜索；本次未安装替换应用、推送仓库或部署服务端。
