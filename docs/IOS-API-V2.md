## 标识、同步和缓存

`GoV2Transport` 和 `GoV2Adapter` 连接 Go v2；保留的 `APIClient` 将既有视图请求转换成资源接口。API 地址必须以 `/api/v2` 结尾，WebSocket 从它推导为 `/api/v2/realtime`。拒绝凭据 URL、查询参数和重定向，HTTP 不使用 Cookie/缓存。

- 用户、会话、申请和会话令牌记录使用按服务器/实体类型持久化的 UUID 对照；本机数字键不作为公开账号或群号，也不会写入网络 UUID 字段。旧数字用户二维码由服务端迁移映射解析，旧群号通过独立 `group_number` 字段发送，不能作为本地查找键。
- 消息视图 ID 使用会话内 seq。iOS 16+ 的 64 位 Int 保留 Go Int64 序号范围。编辑/撤回/删除携带会话及真实 UUID，转发携带来源 UUID，服务端重新校验可见性。
- 版本在消息 body 的 `_go_version` 中保存，显示编辑时间独立。旧响应不能降低版本，撤回记录按会话和消息组合隔离。
- 登录态按服务器隔离；Go 不恢复旧 PHP 的全局 token。账号捕获共享当前登录的成员版本上下文，更换 token 后重建。
- 快照续页携带首个响应的 membership_version，不能从其他并发请求的最新版本替换。409 后清理当前页面并重新读取。
- SQLite 持久记录 membership_version；重入群清理旧代缓存。Go 页面进入/前台恢复和更早历史读取先校验服务器权限，不把尚未授权的旧磁盘消息先展示出来。群身份/个人历史变化会失效正在进行的读取。
- Go 每个登录只允许一条 WebSocket：AppSession 的收件箱持有连接，聊天页观察同账号同服务器的通知。避免首页和聊天页互相踢连接。消息发送仍通过带 request_id 的 HTTP 接口。

## 在 Mac 上继续验收

从仓库根目录执行无签名模拟器构建：

```bash
xcodebuild -project ios/PulseIM.xcodeproj -scheme PulseIM \
  -configuration Debug -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```

默认调试 API 地址 `http://127.0.0.1:18080/api/v2` 指向运行 iOS 模拟器的 Mac。Go 若在另一台机器，需填写手机/Mac 可访问的地址；调试版在原“选择线路”入口检测并保存，切换前退出当前账号。Release 必须用实际 HTTPS 域名和相同源的 WSS 路径，通过原有发布门禁并配置签名。

协议回归入口 `ios/Tests/run-core.sh` 接收绝对路径 JSON：`base`、`prefix`、`password`。先创建四个新的隔离账号 `<prefix>a/b/c/d`，只有 a 标记 internal_staff。回归会修改测试账号的密码、关系和群组，不使用实际用户数据。Linux 的 WebSocket 限制会明确列入报告；在 Mac 上会运行 URLSession 握手和通知段。

页面验收顺序：两个账号登录并临时聊天 → 隐私拒绝/例外/拉黑 → 默认关闭与开启历史的邀请 → 退群重入 → 修改/撤回/转发 → 后台/前台/断网恢复 → 多账号切换与应用重启。特别观察首页/聊天页是否始终只有一条连接，旧身份消息是否在重入后消失。
