## 接口与本地标识

`GoV2Api.kt` 将既有视图模型转换为 Go 的 UUID 资源；视图中的数字仅为本机查找键，不作为后端用户身份发送。`GoV2Ids.kt` 将 UUID 对照持久化在应用私有、禁止备份目录中，按服务器和实体类型隔离。登录凭据仍由原 Keystore 加密存储，并为 Go 服务地址单独分区，切换服务器不会混用另一台服务器的登录态。

消息视图 ID 使用**会话内 seq**，所有编辑/撤回/转发同时携带会话和消息 UUID；消息版本缓存按会话隔离，迟到响应不能降低编辑版本。阅读和历史范围按 seq，显示时间按设备时区转换，版本判断独立于显示时间。保留原视图的 Int 边界，超过 2,147,483,647 的单会话序号会明确拒绝并要求升级，禁止静默截断；这不是服务器序号的限制。

客户端历史读取使用受授权的消息快照页，固定上界、成员版本、清空水位、个人删除和撤回过滤均由服务端执行。WS 只作变化提示，恢复当前已加载窗口；原本后台历史归档及缓存机制保留。目录列表按屏幕页读取，不为每页重复全量拉取全部会话；服务器合并查询私聊权限和最新消息，新增 006 索引支持好友/申请目录。

未读摘要最多计至 999，超出附带 unread_truncated，不宣称为精确无限计数。当前目录分页是 UI 读取视图，消息恢复仍使用有固定上界的游标，不以目录页号充当消息游标。

## 构建与调试

原工程 Gradle wrapper 已对齐本轮验证使用的 8.10.2，保留 Android Gradle Plugin 8.7.3、Kotlin 2.0.21、compileSdk 35、minSdk 26。没有升级界面框架。

默认 `PULSE_BACKEND_PROTOCOL=go-v2`。需要对照旧服务时可显式构建 `-PPULSE_BACKEND_PROTOCOL=legacy`；本轮没有验证 legacy 模式运行，也不在 Go 模式自动回退。

```powershell
# android/local.properties 指向本机 SDK；此文件不提交。
# 本机全局 init.gradle 会注入仓库时，请使用独立 GRADLE_USER_HOME。
gradle -g D:\IM\.local\gradle-android -p android :app:assembleDebug `
  -PPULSE_API_URL=http://10.0.2.2:18080/api/v2 `
  -PPULSE_WS_URL=ws://10.0.2.2:18080/api/v2/realtime
```

调试版可从原有“切换线路”入口填写服务地址，格式为 `http(s)://主机:端口/api/v2`；WS 地址由该服务地址推导。模拟器使用 `10.0.2.2` 访问电脑；实体手机需填写可达的电脑局域网地址，并让开发服务监听该地址。正式版继续要求 HTTPS/WSS 与发布配置，不能由调试地址选择器改写。

## 验证方法

Go 使用 `scripts/verify-core.ps1 -Race`，只运行 localhost 的 `pulse_core_test` 和独立 Redis。

Android 使用真实 APK 和独立 Android 12 模拟器。`GoV2Probe.kt` 是 androidTest 专用 Instrumentation，运行真实 ApiClient/SocketClient，请求本机 Go/PostgreSQL/Redis；检查临时聊天、幂等、编辑、隐私/屏蔽、历史勾选、重入版本、清空/删除、好友、WS、未开放功能及 UUID 对照。仅允许显式传入本机测试地址与测试账号。

```powershell
gradle -g D:\IM\.local\gradle-android -p android :app:assembleDebug :app:assembleDebugAndroidTest
# 安装 app-debug.apk 和 app-debug-androidTest.apk 后，向测试 runner 传入本机 base、prefix、password。
# 测试账号为 prefix+a / prefix+b / prefix+c，必须预先创建在隔离库；不可使用生产账号。
```

UI 验证沿用原页面实际打开聊天列表和群历史，并检查临时聊天按钮、隐私设置、邀请历史勾选。签名发布包、实体手机、后台推送、长时间断网与万人在线容量仍未验收。
