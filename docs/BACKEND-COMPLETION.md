本轮已将账号与安全、联系人与群、消息与媒体、通知与推送、后台管理、任务工资、分发、Telegram、维护和运维入口接入默认 Go 进程。扩展契约见 [API v2 扩展](API-V2-EXTENSIONS.md)。代码、路由和测试存在只代表当前实现可检验，**仍需用旧库数据与各端实际使用逐项验收，不能据此宣称已经完成 PHP 全量替代**。

图片先流式写盘并校验大小与 SHA-256，再进入有界处理队列。支持保留原图或压缩，限制单图 24M 像素、最长边 12000、共享解码预算 512 MiB。拥塞时返回可重试的 429；客户端按原请求号重试，不能把 429 当作已经发送成功。音视频用 ffprobe 验证真实容器，部署时需持久私有媒体目录。

本机隔离 PostgreSQL/Redis 已执行普通测试、race、vet、Windows 构建及 Linux/amd64 交叉构建；容量压测结果见 [压测报告](BACKEND-LOAD-2026-11-11.md)。交叉构建不等于 Linux 实机验收，模拟 APNs/FCM/Telegram 不等于真实设备到达。当前没有使用生产数据库或真实推送凭据，旧 MySQL 数据迁移及新旧记录对账尚未验收；迁移盘点与阻断条件见 [旧库迁移](LEGACY-MIGRATION.md)。
