# 四端 Go 接口审查与修复

本轮从 `dcfdafe` 开始审查 Android、iOS、PC 和 Web 的接口适配、调用方及 Go 契约，保留现有布局和样式。Go 后端与数据库迁移没有修改。初始工作区干净，新增测试、源码修复与本报告均属于本次任务。

## 修复的问题

| 优先级 | 问题 | 修复与证据 |
| --- | --- | --- |
| P1 | Web/PC 切换账号后，迟到的头像授权可能使旧资料请求继续返回；Android 复用 ApiClient 时也可能沿用媒体授权或在多步请求中换用另一个账号 | 浏览器请求在传输和适配完成时检查登录代次，旧授权不能命中新登录缓存；Android 原子保存凭据与代次，冻结每个请求和上传的凭据，并清理会话缓存。修复前浏览器回归复现旧资料成功返回，修复后拒绝；真实 Android 探针通过 |
| P1 | 历史页等待媒体授权时，另一请求可能已推进群成员版本，旧页仍继续组装消息 | Web、Android、iOS 在媒体处理后再次检查本次成员版本。浏览器并发回归及移动端重入、旧快照场景通过 |
| P2 | Android 在备用线路收到实时通知时，以备用地址生成本地会话 ID，无法匹配主线路下已打开的聊天 | SocketClient 单独保留业务服务器身份；真实模拟器经另一个 TCP 端口连接 WebSocket，通知仍命中原会话 |
| P2 | Android 联系人详情使用精简用户接口，备注、分组、公开 ID 等信息缺失，bio 也未转换成签名 | 改走受权限和隐私校验的完整资料接口，补签名和在线隐藏字段；模拟器检查备注、分组、签名、公开 ID 和头像 |
| P2 | Web/PC/iOS 的群设置忽略 is_pinned，调用成功但群并未置顶 | 置顶和免打扰合并为带版本的偏好更新；仅置顶及同时修改两项均有回归 |
| P2 | Web/PC 联系人分组用空字符串清除时恢复旧值，仅修改分组还可能清空备注 | 区分省略字段与明确清空，保留未修改字段；单元回归及实际 Go 请求验证 |
| P2 | Web/PC 按个人名片搜索时向 Go 发送 contact_card，Go 类型实际为 contact | 对齐类型映射；真实发送名片后按类型搜索命中原消息 |
| P2 | 聊天气泡的图片预览逻辑只识别 PHP 链接，Go 图片直接下载完整内容 | Web/PC 气泡使用独立预览地址，Android/iOS 识别 Go 的 preview 路径；查看和下载继续保留 content 原图地址。真实上传、原图摘要和预览读取通过 |
| P2 | 上传在大小校验前读取或计算整个超限文件，浪费内存和处理时间 | 三端适配器与 Go 类型限制一致：图片/头像/音频 10 MiB、文件 50 MiB、视频 100 MiB；浏览器在读取 ArrayBuffer 前拒绝，Android 在散列前拒绝，并冻结上传会话 |

## 验证结果

- 静态清单逐项核对 Web 62、PC 71、Android 82、iOS 77 个路径片段，映射检查无遗漏。覆盖文件中的差异包含改动后更新的源码行号，不代表所有业务界面都已验收。
- Node：19 项测试通过，包括本轮新增的会话隔离、迟到响应、分组清空、置顶、缩略图、大小预检和原有线路、后台回归。
- Web/PC 共用适配器：115 次真实本地 Go/PostgreSQL/Redis 请求，覆盖配置、资料、好友、临时聊天、幂等、CAS、引用、回执、搜索、群历史、成员、置顶、分组、通知、普通图和原图上传下载。预期拒绝的操作按对应错误码验收。
- Android：离线构建调试与测试 APK；真实 Android 12 模拟器 21 组场景通过，包括备用线路 WebSocket、图片/文件/音频/视频上传、完整资料、答题保存、判题、工资与结算重新读取。
- iOS：54 个 Swift 文件语法解析，实际 Foundation 适配器与模型编译，16 组真实本地 Go 请求场景通过，包括置顶、隐私、成员历史、编辑限制、好友、任务答题与结算。
- PC 原有 `npm --prefix pc run check`、Web 脚本语法、共享源码同步、静态覆盖检查通过。

测试仅使用新建的隔离数据库、Redis 逻辑库及临时账号，不向生产账号发送消息。旧测试中把已经实现的任务、置顶等功能当作 501 的断言已更新；群内文件发送继续遵循既有业务限制，文件发送正向测试使用私聊。

脱敏结果、源码及调试包摘要见 `evidence/client-review-2026-11-13.json`。可重复执行的测试为 `client-tests/go-contracts.test.cjs`、`client-tests/go-integration.cjs`、Android 的 `GoV2Probe.kt`、iOS 的 `GoV2Integration.swift`；集成测试必须使用独立测试账号，不能指向生产数据。
