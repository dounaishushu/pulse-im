# 管理后台框架重构

## 范围与边界

原后台基线为提交 `8d8db089e11de8a0d83f574b70d97388fc2af851`。按原页面与实际操作迁移至 Vue 3、TypeScript、Vite 8、Tailwind CSS、Element Plus 与 Art Design Pro 视觉体系；浅色和深色均覆盖导航、表格、筛选、表单、抽屉及弹窗。

17 个业务页面独立实现。原“探索配置”合并进客户端配置中的“探索与商城”，保留 `#/explore` 跳转。原先隐藏的后台账号入口恢复，仍仅超级管理员可见。

本轮未修改正式服务器、数据库或防火墙。构建包和配套 Go 修改需要作为下一次完整发布一起更新。

## 契约补漏

- Go 列表查询在分页前执行管理员账号、任务、敏感词、群组和分发筛选。
- 用户列表/详情补上最近成功登录 IP 与时间，仍不返回密码散列。
- 表单选择器仅提供 ID 与显示名；群组/分发管理权限足以完成对应编辑，不需要额外获取完整用户数据权限。
- 用户查看权限允许读取已缓存的 IP 归属地，不授予外部归属地刷新权限。
- 用户分发目标在事务内按普通临时聊天的隐私规则转换为会话；拉黑和隐私设置在保存及真实发送阶段继续生效。
- 编辑第二页及之后的敏感词、任务、管理员账号使用列表缓存版本或有界翻页，避免固定前 100 条限制。
- 任务启停仅发送 Go 接受的字段，不把只读数据库列原样回传。
- 公告、客户端配置、清理计划、线路及编辑表单保留读取时版本，处理并发修改冲突。
- 客户端日志筛选正确转发 `client.diagnostics`，分发列表展示真实执行状态。
- 群组与频道类型可以在保留成员和历史的前提下转换，推进成员权限版本，防止旧权限缓存继续发言。
- 旧 PHP 的客服属于成员会话分类；迁移 061 单独保留管理分类，消息内核继续使用普通群组权限。未新增独立客服分配队列。已有迁移数据若此前未保留原分类，需要在生产只读核对旧数据后再恢复，不能凭群名猜测。
- 用户检索和消息筛选同时支持迁移前的 16 位公开 ID、旧数字 ID 与新 UUID，避免浏览器内部映射编号覆盖旧编号含义。

## 验证说明

验收证据写入 `docs/evidence/admin-redesign-2026-11-14.json`。浏览器验证连接本机独立 Go 实例和独立 PostgreSQL 测试库；真实上传、保存、导入、导出和批改不是 mock。

这份对照覆盖本次后台迁移，不代表此前 162 项跨四端业务需求已经全部完成 PHP/Go 语义等价验收。

## 布局与滚动修正

应用框架限定在当前可视窗口内。侧栏固定为 208px（折叠后 64px），品牌区与顶部栏高 60px，标签栏高 42px；侧栏底部重复的账号、头像和退出按钮已移除，退出入口保留在顶部账号菜单。菜单和右侧内容各自滚动，切换页面或刷新时重置内容位置，并将当前菜单与标签滚入可视范围；移动端点击当前页面菜单也会关闭导航。

宽表格在表格内部横向滚动，工具栏按钮换行，避免撑开工作区。抽屉宽度受视口约束，标题和操作区保持可见，正文独立滚动；弹窗也限制宽高，内容滚动不会带动背景。地图上的普通滚轮滚动页面，按住 Ctrl / Command 再滚轮缩放，按钮缩放、键盘缩放和放大后拖动继续可用；未放大时允许触屏竖向滚动。

仪表盘去掉强制的卡片最小高度，按内容容器宽度切换列数。异地登录没有记录时显示紧凑空状态；真实记录、错误提示、刷新及分页继续保留。公共分页在没有记录时不展示无效的翻页控件。

界面遵循“通过布局解释结构”的要求：各页只保留标题与操作，移除重复的表格标题、仪表盘解释段落、快捷入口副说明、登录页口号和重复页脚。真实统计、账号与编号、配置字段含义、错误、权限与清理后果继续保留。

新增 `admin-layout.spec.ts` 的 3 条浏览器回归：固定框架与真实滚轮、17 页面 × 2 宽度 × 2 主题的 68 组布局检查，以及平板/手机、两主题下搜索弹窗和 4 类编辑抽屉的滚动检查。与原 3 条业务回归合计 6 条用例全部通过，均连接本机隔离 Go/PostgreSQL；截图使用普通视口，包含滚动前后状态，详细尺寸保存在验收证据中。本轮没有重新运行 Go 全量测试，没有部署正式服务器。

构建及发布方式见 `admin/README.md`。旧发布保留可回退，新版部署不需要修改公网端口规则或引入 HAProxy。
