# Pulse IM 功能清单

整理日期：2026-11-09（北京时间）

本清单根据当前应用源码、服务端路由和客户端工程整理，供功能了解、开发交接与验收使用。“已有”表示存在相应实现，不等于本次已完成生产部署、全平台构建或真机验收。旧文档与当前代码有差异时，以当前路由与实现为准。

| F06 | 联系权限 | 加好友与资料可见性限制、群成员互加好友开关；内部人员依授权范围查询资料、筛选或强制添加好友。 |
| F07 | 会话 | 私聊、群聊、频道、客服和收藏会话；列表增量刷新、未读数、免打扰、置顶、隐藏/重新打开、草稿及个人历史清空。 |

| F16 | 通知 | 通知列表、摘要和已读、新好友与群公告提醒、免打扰、未读角标；PC 托盘与桌面通知，移动端推送设备注册。 |

## 3. 群组与频道

| 编号 | 模块 | 当前已有功能与边界 |
| --- | --- | --- |
| G01 | 群生命周期 | 创建群、修改名称/头像/简介、群公告、转让群主和解散群；建群及管理受权限控制。 |

| G05 | 群内权限 | 群成员互加好友开关、资料入口限制、消息与成员管理权限校验。内部人员身份、群角色和后台角色分别处理。 |
| G06 | 提醒与置顶 | @ 指定成员、按权限 @ 所有人、公告提醒、每会话最多 20 条共享置顶及定位。 |

| G08 | 群人数 | 后台设置展示人数，真实成员变化反映到展示值；真实成员数和容量校验独立处理。 |
| G09 | 频道 | 频道会话、关注和相关消息展示，具体管理能力按服务端授权。 |

## 6. PC 专有与各端差异

| 项目 | PC / Web | Android / iOS |
| --- | --- | --- |
| 多窗口 | PC 主窗口、独立聊天/图片/聊天记录窗口，多账号隔离和窗口布局记忆；Web 不具备 Electron 原生窗口能力 | 原生页面和账号切换 |
| 桌面工具 | PC 截图、托盘、桌面通知、快捷键、字体/字号、主题、下载任务和内部群发助手 | 原生相册/拍摄、录音和媒体查看 |
| 群投票 | PC/Web 有交互界面 | 未发现原生投票交互 |
| 任务与探索 | 未发现同移动端的业务页面 | 有任务答题、结果和配置网页入口 |
| 注册 | PC 必选头像、五位图形验证码；Web 仍有用户名/手机号、昵称、确认密码及五位验证码，未包含 PC 的新头像注册组件 | 头像、用户名、昵称、一次密码及四位数字图形验证码 |
| 图片批量发送 | PC 拖放/粘贴/追加，每批最多 20 张、单张 10 MB；不代表所有附件统一采用该限制 | 原生图片选择/预览，多媒体限制按入口校验 |
| 本地历史 | PC IndexedDB 与磁盘媒体缓存 | Android/iOS SQLite 与媒体缓存 |
| 系统推送 | PC 桌面通知 | FCM/APNs 接入代码；需要真实配置，Android 未包含各手机厂商独立推送通道 |

PC 电话按钮用于音频设备检测，摄像头入口用于预览/拍照，均不能作为已实现实时通话的证明。

## 7. 服务端与部署能力

- WebSocket 鉴权、会话订阅、在线状态、实时消息事件和断线同步。
