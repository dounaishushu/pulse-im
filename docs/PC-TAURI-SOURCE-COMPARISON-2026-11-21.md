# PC 旧版本与 Tauri 源码对照

基准为 GitHub 发出的 2.4.182 和 2.4.192 安装包及 `codex/go-rewrite` 的 2.4.194 源码。主表把 144 个源码和资源文件逐条映射到新版位置。各项目的运行结果在验收表和验收记录中单独列出。

Windows 的 2,997 个表情资源按资源组核对，依赖文件由锁文件和实际包验证。两个旧包另外包含动态生成的 `runtime-config.json`，新版以 `backend.rs`、`routes.rs` 和 Tauri 构建配置接入 Go。两包运行配置均未启用旧 PHP 的签名线路表。
