# 2026-11-15 Go 与管理员后台反馈修复

本轮仅发布服务器 Go 和管理员后台。PC、Android、iOS、用户 Web 的客户端修改暂缓；工作区此前的客户端缓存改动未纳入本次提交和部署。

## 已修复

- 群资料响应补齐 `status: active`。旧客户端的群主菜单、邀请对话框会检查这一字段；此前 Go 只有角色而缺状态，导致合法操作被禁用。
- 普通成员的 Go 成员搜索与可见成员目录对齐，昵称、账号、公开 ID、备注均可匹配；群成员隐私限制和频道权限保留。`can_search` 与 `can_mention_all` 分开，普通成员不获得管理权或 @ 全体权限。
- 移除/重新邀请成员、转交群主、后台指定群主时，同时清除永久和定时禁言，修复 `muted=false` 但 `muted_until` 残留的状态不一致。
- 同一登录会话、同一媒体复用随机授权地址，身份别名最长 24 小时且不超过登录有效期。实际媒体许可仍为 120 秒，每次续期前和每次读取时均检查会话及媒体可见性。注销、移出群、撤回、个人删除等权限检查仍执行。
- 批量媒体授权由逐个 SQL 检查改为单次集合查询；图片及管理员图片增加账号/会话隔离的 ETag 与 `private, no-cache, must-revalidate`，允许经过权限校验后的 304，避免重复下载正文。JSON、错误及认证响应继续禁止缓存。
- 携带有效媒体授权的图片允许在桌面自定义来源中嵌入，修复 `same-site` 资源策略造成的图片被浏览器拦截；需要 Bearer 的接口保留原资源策略。
- 批量建号恢复旧 PHP 的 8—128 字节密码规则、1—999999999 起始编号、1—100 数量；补前缀、账号范围、重复账号错误提示。请求与界面超时统一延长到 150 秒，原 Argon2 参数不降低；相同提交重试及并发重试不重复创建。
- 后台开关显示已开启/已关闭，禁言开关显示已禁言/可发言。新增独立“修改密码”操作，保存后旧登录会话失效。
- 分发编辑与详情逐步显示累计延迟后的 `YYYY-MM-DD HH:mm` 北京时间；修改延迟即更新。Cron 预览使用 Go 调度器同一解析器；详情重新请求当前数据，避免使用列表旧副本。
