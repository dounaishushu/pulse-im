# PC 群资料成员禁言标识

对应 PC **2.4.174 / Windows x64**，2026-11-17。

群资料成员列表原来只显示群主或管理员角色，没有展示成员接口已有的禁言状态。现在在成员行右侧增加红色禁言图标和“已禁言”文字，支持永久禁言、定时禁言及全员禁言。角色标识继续显示，姓名较长时省略，禁言标识保持可见。

全员禁言只标记普通群员，群主和管理员按原规则豁免；单独禁言以接口返回的成员状态为准。定时禁言到期后，在原列表自动移除标识。解除禁言后的成员刷新或现有成员管理成功回调会更新标识；搜索结果同样显示。浅色和深色主题均配置相应颜色。

使用现有已授权的群成员列表、搜索结果和群资料，不新增查询其他成员的权限或服务端接口。普通群员仍按原规则查看群主、管理员以及允许搜索的群内好友。
