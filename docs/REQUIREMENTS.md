# Pulse IM 完整功能与需求基线

日期：2026-11-09。此文档是 Go 重写范围，不是完成声明。30 个原始模块、166 个功能编号完整保留。HTML 用作旧业务说明，TXT 的删改和权限截图优先；用户后续明确指令优先于旧材料。

## 已确认的用户要求

- Go 后端；保留现有 PC、移动端、Web 前端代码，随后改接新接口；不引入另一套前端。允许规范 HTTP/WS 接口。
- Redis 纳入基础架构；RocketMQ 根据独立消费者与实测积压决定，向量库按真实功能需求决定；不引入多余业务。
- 单机、模块化单体，不做集群；按 4 核、8 GB 起步及 16 GB 上限规划。至少 10000 条在线连接，日常聊天为主要负载。消息写入吞吐和群广播另行验收。
- 新库选 PostgreSQL；现有服务器上的 MySQL 数据可迁移。暂按保留账号、好友、群、消息、回执、附件及任务记录设计，正式切换前核实迁移范围与数据量。
- F024 客服、F054/F055 群投票、F161 IP 白名单取消；F050 永久禁言/解除；F107 每账号独立后台入口。
- F114 已确认改为密码重置，不保存可还原密码。
