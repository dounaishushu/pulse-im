# PC 备注、群权限和管理员设置修复

版本：Tauri PC 2.4.205。本次保留本地此前的群聊、头像和待发队列修改。

## 备注显示

资料页仍自动保存备注和好友分组。成功保存后立即更新当前账号的名称缓存，私聊标题、会话列表、群成员名称和会话搜索使用同一份备注。清空备注后恢复昵称；目录刷新不会把新备注覆盖回昵称。未成功保存的草稿不会改动会话标题。

## 群权限

面板包含发送消息、禁止群成员互加好友、邀请新成员、置顶消息、修改群组信息、例外。

- 发送消息对应现有全员禁言的反向状态。关闭后普通成员禁言，群主和管理员仍按现有权限发言。频道普通成员仍为只读。
- 禁止互加好友使用现有服务端群隐私规则，保留群内查看资料和好友请求的限制。
- 邀请新成员新增 `allow_member_invites`。默认 `false`，保持原有群主和管理员邀请规则。允许后普通群员可通过 PC 聊天“更多操作 → 邀请新成员”发起邀请；普通成员侧栏仍只显示通知。候选名单和实际邀请均在服务端校验当前群权限及目标用户隐私。
- 普通成员不能授予新成员入群前历史记录；界面隐藏该选项，服务端也拒绝绕过界面的历史授权请求。
- 置顶消息、修改群信息保持仅群主及管理员有权操作，显示锁定提示。
- 例外使用现有单独禁言能力，支持搜索普通成员、设置永久或定时禁言、解除禁言。这里的操作立即生效，全员禁言仍优先执行。列表为服务端筛选和游标分页，过期禁言不计入名单或数量。
- 类型、公告和三个可编辑群权限先暂存，回到“编辑群组”点击保存后生效。

## 管理员

默认显示群主和管理员；输入备注、昵称、账号或 ID 后搜索全体群成员，输入停止 300 毫秒自动查询。群主可直接设置或取消管理员，保存立即生效。操作前重新读取成员权限；并发任命已完成时不会反向取消。管理员不能任免管理员或转让群主，服务端仍以当前身份校验。

## 后端更新要求

备注显示和管理员搜索可配合当前后端使用。普通成员邀请开关、例外名单的服务端筛选和准确计数需要更新 Go 后端。

新增迁移 `server/internal/core/migrations/065_group_member_invites.sql`，只新增一个默认 `false` 的布尔字段；不清空或重写聊天记录和现有资料。迁移由 Go 后端的 `migrate` 命令读取内嵌 SQL 执行；`serve` 会检查结构版本，不会自动迁移。

部署时使用项目现有生产配置和卷，先按现有流程保留数据库备份及旧镜像，构建包含本次源码的新后端镜像，再用同一生产连接配置运行新镜像的 `migrate` 命令，最后启动新版本并检查服务健康。具体 Compose 服务名应从实际服务器配置读取。本次未连接或修改生产服务器。

旧服务器未返回新增字段时，PC 会明确禁用邀请开关和例外入口，其余设置和备注、管理员修复仍可使用。

## 验证范围

客户端单元测试、Vue 类型检查与资源构建、真实 Vue 组件/useChat/Go-v2 适配器的隔离 HTTP 界面联调、Go 单元测试与静态检查。新增 Go 数据库集成用例覆盖邀请开关撤销、隐私、历史授权和禁言名单，需要本机独立 PostgreSQL/Redis 测试环境；未配置时会跳过，不等同于数据库验证通过。没有使用真实生产账号执行任免、邀请或发消息。
