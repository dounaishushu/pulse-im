- 增加纯 JVM `ChatFrameStats`：读取 gfxinfo 的应用汇总；严格检查 p99 < 16ms、卡顿率 < 1%，按原始帧计数计算卡顿率。

## 后续修复：多选局部刷新（同日）

原代码在多选模式中每次选中/取消单条消息，都会向全部消息发送选择刷新。在修改产品代码之前，新增设备回归稳定复现了 `Single deselection notified 205 rows`。

新增纯 Kotlin `ChatSelectionUpdates` 保存选择状态快照。进入/退出多选更新全部消息以调整宽度；模式不变时只更新勾选状态变化的消息，重复状态不发通知。按消息 ID 定位当前索引，排除加载头与待发行；延迟刷新会丢弃过时请求，继续保留阅读锚点。

修复后群聊、私聊均验证单次选择/取消只通知 1 行，重复选择状态通知 0 行，保留行实例及阅读位置。新增 12 项 JVM 测试，总计 69 项通过；新旧路径构建通过，旧路径 4 项回归通过，群聊/私聊初始截图哈希与上述基准完全相同。
