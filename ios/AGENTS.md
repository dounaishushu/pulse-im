# iOS 工作约定

用户于 2026-11-28 明确要求：iOS 修改完成后必须有可见的版本号变动。

- 每轮 iOS 功能修改或缺陷修复交付时，同步递增对外版本号和构建号；默认补丁版本加 1、构建号加 1。同一轮尚未交付的补改沿用该轮版本，不因保存文件或重复构建再次递增。
- 对外版本统一读取 Xcode 的 `MARKETING_VERSION`，构建号读取 `CURRENT_PROJECT_VERSION`。`PulseIM/Info.plist` 使用对应构建变量，Debug 和 Release 必须一致。
- 本轮配置为 `1.0.1`、构建号 `95`。后续在当前配置基础上递增，不回退或重复使用已交付版本。
- 完成版本配置变更后检查工程和 plist。源码版本已修改、安装包已生成、手机已安装是不同状态，报告中如实说明。
