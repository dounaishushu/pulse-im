# Art Design Pro

This application uses and adapts Art Design Pro's theme tokens and statistics card
structure, with Element Plus as its component library. Business modules, API wiring,
accessibility, route permissions and layout integration are maintained in this project.

Source: https://github.com/Daymychen/art-design-pro
